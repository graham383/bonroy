# BonRoy Services demo website

Static redesign demo for BonRoy Services (Burlington / Oakville landscaping).
Open `index.html` or deploy the folder as-is on Vercel (no build step).

## Images
Everything in `images/` is conceptual, generated imagery used as placeholders. It is not actual BonRoy work, staff or fleet.
Replace with customer-approved photography before launch. A native 2400px+ photo is recommended for each hero slide.
